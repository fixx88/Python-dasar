# Python Dasar - Bab 02 sampai Bab 11

Cara pakai di VS Code:
1. Ekstrak ZIP, lalu File > Open Folder > pilih folder `python_dasar`.
2. Buka file .py, klik tombol Run (segitiga) atau jalankan `python nama_file.py` di terminal.
3. Gunakan Python 3.10+ (match-case di bab 05 butuh 3.10+).

Catatan:
- 02_input.py (bab 03) dan 02_try_except.py (bab 09) meminta input dari keyboard.
- Bab 10/02_module_sendiri: jalankan `python main.py` dari dalam folder tersebut.
- 04_pandas.py (bab 11) butuh `pip install pandas`.
- Bab 01 hanya berisi pengantar & hello.py (disertakan di folder bab_01).
